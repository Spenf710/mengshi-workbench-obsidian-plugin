# 会话知识收割 SKILL（通用版）

> 随猛士驾驶舱分发的通用收割技能模板。**不含任何个人隐私**：不指向特定目录、不包含个人路径、不引用内部知识库结构，安装后按自己的实际情况微调即可。

## 这是什么

一个 Claude Code / CodeM 的自定义 Skill，作用是**把你和 AI 的每一段对话沉淀进自己的 Obsidian 知识库**：回顾对话 → 按主题归类 → 更新已有笔记或新建 → 更新项目索引。

配合驾驶舱的「✅ 已收割」标签：只要会话中出现过收割调用，就会被标记。如果不想用默认名 `session-harvest`，可在插件设置 → 🌾 收割技能 →「收割技能名」里填你自己的名字（多个用逗号分隔）。

## 安装方式

1. 把 `SKILL.md` 放进你的 Claude Code 技能目录：

   - **Claude Code**：`~/.claude/skills/session-harvest/SKILL.md`
   - **CodeM**：参考你的 CodeM 技能目录（通常 `~/.agents/skills/` 或 `~/.codem/skills/`）

2. 按你的知识库结构微调 `SKILL.md` 里的「目标目录」（Step 2 表格的下方表格项）

3. 需要时在对话里说 **"收割" / "总结对话" / "归档对话"**，或使用斜杠命令 `/session-harvest` 触发

## ⚠️ 隐私说明

本模板**不含任何隐私信息**，可放心分发 / 随插件公开仓库提供。
